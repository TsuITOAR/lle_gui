# LLE GUI

An interactive simulator for the [Lugiato–Lefever equation](https://en.wikipedia.org/wiki/Lugiato%E2%80%93Lefever_equation) (LLE), built in Rust with [egui](https://github.com/emilk/egui). It runs natively and in the browser.

**[▶ Live demo](https://tsuitoar.github.io/lle_gui/)** — no install needed, runs anywhere, even on your smartphone.

## Features

- Real-time simulation with live-adjustable equation parameters
- Real-domain and frequency-domain views of the field
- History recording with a GPU-accelerated 2D colormap view of the field evolution
- Checkpoints: save and restore simulation states, with save/load to file
